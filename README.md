# THE PITCHPRENEUR — Website starter

A responsive static website for a Kenyan PR and communication professional and founder of Misheveve.com. Built with HTML, CSS and vanilla JavaScript; no build step is required.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Open `site-config.js` and add a public contact email and social profile URLs.
2. Review the About section so education, experience and credentials are accurate.
3. Confirm the exact role, deliverables and outcomes for Kenya Seed @70 and Moi University Main SDA Campmeeting 2026 before claiming them.
4. Add an approved CV and portfolio PDF under `assets/`, then link them on the resources section.
5. Review the privacy notice and terms for your actual setup.
6. If you want a custom domain, purchase/register it separately and connect it in Vercel.

## Publish on Vercel using GitHub
1. Create a new GitHub repository named `the-pitchpreneur-website`.
2. Upload all files and the `assets` folder from this package to the repository root.
3. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
4. This is a static site: no build command is needed and the output is the repository root.
5. Once deployed, test the mobile layout, navigation, external links and contact form.

## Important
The contact form uses `mailto:` and opens the visitor's email app; it does not send/store submissions through a backend. A public contact email must be configured before launch. Do not add private credentials to these files.
